## mutti env

Print the MUTTI_* variables, for `mutti env | source` (fish) or `eval "$(mutti env)"`

```
mutti env [flags]
```

### Options

```
      --format string   sh or fish (default: from $SHELL)
  -h, --help            help for env
```

### Options inherited from parent commands

```
  -C, --dir string   run as if mutti was started in this directory
      --json         print machine-readable JSON
```
