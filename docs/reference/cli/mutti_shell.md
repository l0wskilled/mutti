## mutti shell

Open a shell in a service (default: the main one), as your host user

```
mutti shell [service] [flags]
```

### Options

```
  -h, --help          help for shell
  -u, --user string   run as "host", "service" or user[:group]
```

### Options inherited from parent commands

```
  -C, --dir string   run as if mutti was started in this directory
      --json         print machine-readable JSON
```
